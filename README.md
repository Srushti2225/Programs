## Description

This repository contains a collection of frequently used C programs
created for practicing algorithms, logic building, and basic programming concepts.

## Programs

1. Bubble Sort - Sorts an array using the Bubble Sort algorithm.
2. Linear Search - Searches for an element sequentially in an array.
3. Factorial - Calculates factorial using recursion.
4. File I/O - Demonstrates writing data into a file.
5. Binary Search - Searches for an element in a sorted array using binary search.


## How to Compile and Run

### Bubble Sort

```bash
gcc programs/bubble_sort.c -o bubble_sort
./bubble_sort

gcc programs/linear_search.c -o linear_search
./linear_search

gcc programs/factorial.c -o factorial
./factorial

gcc programs/file_io.c -o file_io
./file_io

gcc programs/binary_search.c -o binary_search
./binary_search
